زر داخل صف Interactive Grid يقدر يجيب بيانات مرتبطة من غير تحديث الصفحة كلها. المهم توضيح هوية السجل والصلاحيات وطريقة الحفظ.

حدد السجل المرتبط بالزر المضغوط؛ الصف المحدد حاليًا مش بالضرورة هو نفس صف الزر. ابعت المعرف المطلوب لـAjax Callback، وافحص صلاحية الوصول على السيرفر، وارجع استجابة JSON صغيرة.

طبق القيم من خلال Model API الخاصة بالـGrid، بدل تعديل HTML المعروض في الخلية. التغيير الشكلي ممكن يختفي عند إعادة الرسم، وقد لا يصل لنموذج البيانات أصلًا.

حدد هل الاستجابة بتغير نموذج المتصفح فقط، أم تنفذ عملية محفوظة على السيرفر. وضح نجاح الحفظ، وتعامل مع الأخطاء والاستجابات المتأخرة وتكرار الضغط.

البوست الأصلي شارك مقالًا من المجتمع. النسخة دي بتشرح اعتبارات التصميم، ولا تنسب تأليف المصدر الأصلي لي.

المرجع: [توثيق Oracle لـModel API](https://docs.oracle.com/en/database/oracle/apex/24.2/aexjs/model.html).

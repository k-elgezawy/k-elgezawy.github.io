Oracle QUALIFY: تصفية نتائج التحليل بوضوح

English version

QUALIFY makes a familiar reporting task easier to express: filtering rows after an analytic function has been evaluated. Oracle AI Database 26ai documents this clause; verify support in the database release your APEX application actually uses.

One employee per department

Assume EMPNO is unique. This example picks the highest non-null salary in each department, breaking salary ties by employee number:

select empno, deptno, sal,
       row_number() over (
         partition by deptno
         order by sal desc nulls last, empno
       ) as rn
from emp
qualify rn = 1;

The tie-breaker matters. Without a deterministic ordering, equal salaries can produce an arbitrary winner. If every salary in a department is null, this query still selects one employee. If the requirement is to return all tied highest salaries, choose a ranking strategy that preserves ties instead. Oracle: ROW_NUMBER.

Keep the compatible alternative

On a database without QUALIFY, put the analytic calculation in an inner query:

select empno, deptno, sal, rn
from (
  select empno, deptno, sal,
         row_number() over (
           partition by deptno
           order by sal desc nulls last, empno
         ) as rn
  from emp
)
where rn = 1;

QUALIFY is evaluated after analytic calculations; WHERE filters their input rows. Neither query promises a final display order without an outer ORDER BY. Oracle: SELECT and QUALIFY.

Editorial correction: the original post broadly attributed support to “23ai” and claimed faster execution. This revision uses the verified 26ai documentation. Shorter SQL is not evidence of a faster execution plan.

النسخة العربية

QUALIFY بتسهل التعبير عن مهمة متكررة في التقارير: فلترة الصفوف بعد حساب Analytic Function. الخاصية موثقة في Oracle AI Database 26ai؛ تأكد من دعمها في إصدار قاعدة البيانات اللي تطبيق APEX عندك بيستخدمه فعليًا.

موظف واحد لكل قسم

نفترض إن EMPNO فريد. المثال بيختار أعلى راتب غير فارغ في كل قسم، ويحسم تساوي الرواتب برقم الموظف:

select empno, deptno, sal,
       row_number() over (
         partition by deptno
         order by sal desc nulls last, empno
       ) as rn
from emp
qualify rn = 1;

حسم التعادل مهم؛ من غير ترتيب حتمي، تساوي الرواتب ممكن ينتج اختيارًا غير محدد. لو كل الرواتب في قسم فارغة، الاستعلام يظل يختار موظفًا واحدًا. ولو المطلوب كل الموظفين المتعادلين في أعلى راتب، اختار طريقة ترتيب تحتفظ بالتعادل. توثيق ROW_NUMBER.

احتفظ بالبديل المتوافق

لو الإصدار لا يدعم QUALIFY، ضع الحساب في استعلام داخلي:

select empno, deptno, sal, rn
from (
  select empno, deptno, sal,
         row_number() over (
           partition by deptno
           order by sal desc nulls last, empno
         ) as rn
  from emp
)
where rn = 1;

QUALIFY تُقيّم بعد الحسابات التحليلية، بينما WHERE بتفلتر الصفوف الداخلة للحساب. ولا واحد من الاستعلامين يضمن ترتيب العرض النهائي بدون ORDER BY خارجي. توثيق SELECT وQUALIFY.
